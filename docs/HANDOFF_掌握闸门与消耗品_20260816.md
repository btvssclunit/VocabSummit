## 2. 消耗品与竞速道具（仅四座山；码头版本明确推迟，见 §5）

### 2.1 词雨消耗品（7 件，`词雨灵露` 模式适用）

赛前选择，单局消耗，个人练习模式**上限 3 个消耗品槽**。灵露购买。
不影响历练值/海拔/排行榜——词雨本身只产出灵露、不产出 mastery，
所以消耗品在此不违反"可购买优势不得改变排名"的铁律。

| 文件名（已在仓库素材交付批次中，需确认落位路径） | 名称 | 功能 |
|---|---|---|
| `consumable_tanghulu.png` | 糖葫芦 | +1 命 |
| `consumable_dingfengzhu.png` | 定风珠 | 冻结落词 5 秒 |
| `consumable_youzhisan.png` | 油纸伞 | 连击护盾 |
| `consumable_yushan.png` | 羽扇 | 下落变慢 |
| `consumable_suanpan.png` | 算盘 | 单局灵露 +10% |
| `consumable_yuhulu.png` | 玉葫芦 | 落地词自动收灵露 |
| `consumable_jinnang.png` | 锦囊 | 随机道具（等效抽取以上任一件） |

命名去宗教化记录（供参考，不影响施工）：灵露瓶→糖葫芦、护身符→油纸伞、
双倍灵露符→算盘；定风珠、玉葫芦确认为武侠/志怪世俗道具，非宗教物件；
提灯（预览下一词拼音）已整体移除，两个模式都判定为鸡肋。

### 2.2 攀山竞速道具（3 件，新规则）

**规则重开记录**：竞速此前完全禁止购买优势。现允许，但**道具只能改变测试条件
（时间／容错／选项范围），不能替代或降低对词义的掌握要求**——这是唯一的边界，
施工时任何新增道具效果都要先过这条。

| 文件名 | 名称 | 功能 | 适用范围 |
|---|---|---|---|
| `powerup_tonghudilou.png` | 铜壶滴漏 | 加时（计时模式 +5–8s；闯关模式失误宽限 +3s） | 计时模式为主 |
| `powerup_hujing.png` | 护膝 | 首次答错不计时间惩罚，仍须答对才能前进 | 两模式皆可 |
| `powerup_sinan.png` | 司南 | MCQ 类关卡剔除一个错误选项 | **仅限选择题型 waypoint** |

⚠️ **施工前必须先确认**：攀山竞速闯关模式的 waypoint 是否全部为 MCQ，
还是混有填空/拼音输入类型——这决定司南能否在所有关卡生效，或只在部分关卡可用。
这是上次会话就留下的未决项，这次一并列入。

### 2.3 竞技场景道具规则

**核心原则：凡属实时竞技场景，一律禁用道具。**

| 场景 | 道具状态 | 备注 |
|---|---|---|
| 攀山竞速（个人练习） | 允许，上限 3 槽 | 本节新规则 |
| 结伴登峰（房间） | **禁用** | 需确认房间是否复用 `app.js` 主状态；若复用，需要显式禁用开关 |
| 课堂擂台（arena） | **禁用**（已天然满足） | `arena.js` 独立最小渲染器，不产出历练值/海拔/灵露/mastery，本就不接触消耗品库存 |
